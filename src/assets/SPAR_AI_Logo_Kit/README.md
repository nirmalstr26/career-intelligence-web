# SPAR AI Logo Kit

This kit was extracted from the approved SPAR AI brand concept and prepared with transparent backgrounds for code use.

## Folders
- `icon/` — standalone SPAR AI symbol in common app/favicon sizes.
- `wordmark/` — text-only `SPAR AI`.
- `lockup/` — icon + `SPAR AI` horizontal logo.
- `web/` — ready-to-drop favicon, app icon, and navbar assets.

## Which version to use
- Files containing `dark-bg` use the white `SPAR` wordmark and are intended for dark/navy backgrounds.
- Files containing `light-bg` use a dark-navy `SPAR` wordmark and are intended for white/light backgrounds.
- The standalone colored icon can be used on either background.

## Suggested website usage
- Header on current dark SPAR landing page: `web/navbar-logo-dark-bg.png`
- Header on a white/light page: `web/navbar-logo-light-bg.png`
- Browser favicon: `web/favicon-32x32.png`
- Apple touch icon: `web/apple-touch-icon.png`
- PWA/Android icons: `web/android-chrome-192x192.png` and `web/android-chrome-512x512.png`

## Example
```html
<img
  src="/assets/spar-ai/navbar-logo-dark-bg.png"
  alt="SPAR AI"
  width="190"
/>
```

For sharper rendering on retina displays, use a source image around 2x the rendered CSS width.
